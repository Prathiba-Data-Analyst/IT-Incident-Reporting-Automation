# IT Incident Reporting Automation Using Python

## Project Overview

This project demonstrates the automation of a manual Excel-based IT incident reporting process using Python, Pandas, and OpenPyXL.

The objective is to reduce repetitive manual reporting activities by automating data cleaning, analysis, summary table generation, and Excel report formatting.

## Business Problem

Manual incident reporting requires repetitive Excel operations, including data cleaning, pivot table creation, SLA monitoring, and report formatting.

This project demonstrates how these activities can be automated using Python.

## Solution

Developed a Python-based reporting workflow that:

- Imports raw incident data.
- Performs data cleaning and preprocessing.
- Generates priority-wise SLA summaries.
- Calculates incident update frequency.
- Analyzes monthly incident trends.
- Summarizes incidents by category.
- Exports results into a formatted Excel workbook.

## Technologies Used

Python | Pandas | OpenPyXL | Excel |  Google Colab 

## Dataset

The project uses a synthetic dataset of 1000 IT incidents generated using ChatGPT.

The dataset is intended for demonstration and portfolio purposes.

## Automated Reports

1. Priority-wise SLA Analysis (P1–P4)
2. Incident Update Frequency
3. Monthly Incident Trend
4. Incident Category Analysis

## Output

The Python script generates an Excel workbook containing:

**Raw Data:** Incident-level records.

**Summary:** Formatted analytical tables with assignment-group-level breakdowns and grand totals.

## Project Outcome

Successfully demonstrated the conversion of a repetitive manual Excel reporting workflow into a Python-based automated reporting process.

The project highlights practical skills in data manipulation, operational reporting, data analysis, and Excel automation.
